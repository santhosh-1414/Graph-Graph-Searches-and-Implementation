# Graph Search Algorithms – Maze Pathfinding

## Project overview

This project implements and compares three graph-search algorithms for finding a path through the 10 × 20 maze specified in the DV2618/DV2619 assignment.

- Start: (0, 1)
- Goal: (9, 18)
- 0: free cell
- 1: wall
- *: path marker in the visualized output

## Algorithms

- **Breadth-First Search (BFS):** explores the maze level by level using a queue.
- **Depth-First Search (DFS):** explores paths using a stack.
- **A* Search:** uses a priority queue and Manhattan-distance heuristic.

## Project files

- `1.ipynb` – Jupyter Notebook with the maze, algorithm implementations, performance measurements, and path visualizations.
- `AI Report.docx` – Assignment report.

## Running the notebook

1. Install Python 3 and Jupyter Notebook.
2. Open the notebook in Jupyter.
3. Run the cells from top to bottom.
